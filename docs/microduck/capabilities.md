# 已实现的高级控制能力

交接对象是保留模型 `clear-room-realtime-control-pilot-v1 / step 250`。它接收红、蓝、黄球指令及视觉历史，输出转向、行走、头部朝向、停止决策，反复观察环境。官方 RL/ONNX 提供已有行走与平衡能力；此处训练的是其上的任务控制。

目前有用的演示是“无障碍房间中寻找指定颜色球，接近并停稳”。不是通用自主大脑，也不是任意语言指令执行器。目标选择、搜索与接近是整个寻球任务的一部分，尚无每一子能力单独的正式泛化验收。

## 已有证据

20/21 与 27/60 从 `single-obstacle-assessment.json` 中分别按 `scene=room_clear/room_curriculum_one`、`contract=microduck_navigation_v1` 的 rows 重算。其顶层 47 successes 是 **21+60 共 81 集的合计**，不能误写成障碍成绩。扩展动作范围同理。

主要原始 JSON 及 SHA256 随[证据目录](evidence/manifest.json)提供。视频等大工件、逐 tick 原始轨迹未打包进 Git，仍保留在原开发环境；仓库可重新运行生成记录。无年龄限制复测的 [analysis](evidence/plain-no-age-analysis.json) 与新增布局实时 [assessment](evidence/expanded-clear-development-assessment-v1.json) 是不同部署，不合并计算成功率。

## 成功标准和边界

固定指令匹配目标颜色，接近到球表面 0.25–0.40m 并保持至少 2 秒；碰撞、跌倒、超时和控制接管记为失败。实时结果还要求时钟/物理推进通过。案例最长 30 秒，证据说明保留各实验的参数和评测版本。

- 19/21 或 59/60 都是**开发集结果**；不是独立 200 布局正式验收，也不是 TinyVLA 13 项动作验收。
- 相机历史是测量帧的空间拼图，不是模型生成的预测视频。
- 本部署只使用动作输出；没有用想象视频做显式搜索或规划。
- 近期候选、普通球以外的物体、可靠随机障碍、闭环踢球、多技能泛化、CPU 推理和真机能力，不属于这份模型已完成的交付。
- `hardware_validated=false`。当前成绩不能推导仿真到真机必然等效。

本仓库保留当前实现中的后续契约/时序修正。上述报告绑定其历史源码哈希，属于历史证据；[本次导出实测](validation.md)独立列出，不拿历史成绩替代当前提交测试。
